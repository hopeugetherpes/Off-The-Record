# Security policy

## Supported version

Security fixes are applied to the latest commit on the `main` branch.

## Reporting a vulnerability

Please do not publish an exploitable vulnerability before it has been investigated. Report it privately to
`anatole@anatole.co` with the subject `Off The Record security report` and include reproduction steps, affected paths
and any suggested mitigation.

Do not include real credentials, personal data or harmful payloads in a report. A harmless proof of concept is enough.

## Project boundary

This repository builds a static website. It does not make public USB hardware or files obtained from a public drop
trustworthy. Treat both the device and its contents as hostile, and use isolated equipment for inspection.
